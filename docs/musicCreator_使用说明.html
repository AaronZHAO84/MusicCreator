musicCreator

使用说明 · v1.0

一个用于中文歌曲创作、Suno 制作、音频筛选、封面与发布整理的统一工作流。它的作用，是让每首歌少重复说明，多保留真正的创作判断。

最简单的开始方式
使用 musicCreator，帮我创作一首关于……的歌

01 / WHEN什么时候使用

适合调用

  • 开始一首新歌
  • 修改或续写已有歌词
  • 制定 Suno Style 和演唱方向
  • 生成音频并进行试听筛选
  • 制作封面、HTML预览或发布物
  • 整理歌曲版本和创作记录

它会自动记住的偏好

  • 主题确认后先做整体总观
  • 唐恬式歌词气质与成熟男声表达
  • 不说破、少讲道理、光影和时间表达
  • 适当一两处 connected enjambment
  • 版本不覆盖，发布物标出 Aaron，Z作品

02 / FLOW完整创作流程

01主题确认

为什么写、写谁、写什么，以及需要避免什么。

02整体总观

先统一歌名、歌词、Style与演绎的大方向。

03歌名与歌词

提出歌名方向，写歌词，预览、局部修改后确认。

04Style与演绎

确定声线、音域、配器、情绪推进并统计字符数。

05生成与试听

区分准备、生成、试听和最终选定。

06封面

结合已确认歌词与Style提炼画面。

07发布物

统一文字范围、视觉风格和多设备排版。

08归档复盘

保留版本，记录创作背景与共鸣。

03 / CHOICE遇到多个方向时

当歌名、歌词路线、Style、演唱方式、封面或发布风格出现多个并列选项时，可以调用 murpick 制作选择菜单。勾选项和未勾选项都会作为后续决策依据；单一路径或普通局部修改不调用。

04 / FILES歌名确定后的文件规则

默认根目录：

D:\\MyPlaces\\GPT Projects\\自己\\音乐创作\\《歌名》\\

如果默认路径不存在，会先通知你创建或重新指定，不会静默换路径。歌曲文件夹内保存创作记录、歌词、Style、生成说明、封面、音频、预览和 archive。

05 / STATUS进度如何判断

默认：根据产物判断

  • 歌词文件 → 歌词产物已形成
  • Style文件 → Style已准备
  • 音频文件 → 音频已生成
  • 试听记录 → 已试听或已选定
  • 封面/HTML → 对应发布素材已形成

文件存在不等于已经试听、选定、发布或完成视觉检查。

用户可以手动修改

  • 已完成
  • 当前阶段
  • 未完成

手动状态优先于自动判断；重新扫描或恢复自动模式后，才按产物重新推断。

06 / INPUT每次只需提供这些信息

歌曲主题：　人物/事件：　核心关系：　创作缘起：　想表达的内容：　参考材料：　希望保留的意象：　不希望出现的内容：　是否采用喜剧表达悲剧：　是否采用不说破、少讲道理的表达：　演唱偏好：　是否需要音频、封面、发布物：

07 / GATES三个必须确认的节点

整体总观确认整首歌想要什么，不让歌名、歌词和Style各自漂移。
歌词确认歌词确认前只预览，不保存最终文件，不进入后续素材制作。
目录有效默认路径或指定路径无效时暂停保存，通知用户处理。
