# musicCreator

一个用于中文歌曲创作、Suno 制作、演唱方向、音频筛选、封面与发布整理的 Codex Skill。

## 使用方式

直接对 Codex 说：

```text
使用 musicCreator，帮我创作一首关于……的歌
```

Skill 会围绕以下顺序工作：

> 主题确认 → 整体总观 → 歌名方向 → 歌词创作 → 歌词预览与修改 → 歌词确认 → Suno Style 与演绎方案 → 生成音频 → 试听筛选 → 封面 → 发布物 → 归档复盘

## 核心规则

- 主题确认后，先做整体总观，统一歌名、歌词、Style 和演绎方向。
- 歌词先预览，确认后再保存。
- 多个平行方向需要比较时，可使用 murpick 选择菜单。
- 歌名、歌词、Style 和整体演绎，以“传世经典、流行爆款”为质量目标；这是创作要求，不是对传播结果的承诺。
- 演唱不追求过大音量；力量来自清晰旋律线、情绪推进、节奏、气息、重音、和声、音色和编曲变化。
- 禁止高音冲刺、持续高音、喊唱、尖锐头声、强行升调和结尾爆发；副歌不要求一定出现歌曲标题。
- 男女声并用时，副声不能只做和声，应通过尾词接唱、整句交叉、问答或段落切换形成明显对比。
- 长句用节奏重音、停顿和力度变化演绎，保持低音域内的力量和层次。
- 说唱可以快速、密集，但保持低声区和清晰咬字；Spoken 段可在快速说唱后转为低声、缓慢、近距离纯朗读。
- 副歌以低中音旋律、宽和声和鼓组推进制造张力，不靠抬高音区或增大音量。
- 歌词预览前，先结合整首歌词和整体意境检查措辞、逻辑、自然度、演唱顺畅度及需要润色的词句段落。
- 默认使用成熟男声、中低音区、自然叙事和克制推进；具体演绎根据本次歌曲选择。
- 允许适当使用一两处 connected enjambment。
- 可以用喜剧形式表达悲剧，不直接说破、不直接讲道理。
- 歌名确认后，默认使用 `D:\MyPlaces\GPT Projects\自己\音乐创作\《歌名》\`。
- 路径不存在时暂停保存并通知用户。
- 自动根据产物判断进度，用户可以手动覆盖状态。
- Suno Style 必须实际统计字符数，不能超过1000字符。
- 发布物固定标出 `Aaron，Z作品`，并兼容手机、平板和桌面设备。

## 版本规范

每首歌的创作记录包含轻量的“创作背景与共鸣”，记录为什么写、想抓住什么、突出什么和表达什么。已确认版本不覆盖，旧版本进入 `archive/`。
