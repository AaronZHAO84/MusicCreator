# musicCreator

一个用于中文歌曲创作、Suno 制作、演唱方向、音频筛选、封面与发布整理的 Codex Skill。

## 使用方式

直接对 Codex 说：

```text
使用 musicCreator，帮我创作一首关于……的歌
```

Skill 会围绕以下顺序工作：

> 主题确认 → 整体总观 → 歌名方向 → 歌词创作 → 歌词预览与修改 → 歌词确认 → Suno Style 与演绎方案 → 生成音频 → 试听筛选 → 封面 → 发布物 → 归档复盘

## 核心规则

- 主题确认后，先做整体总观，统一歌名、歌词、Style 和演绎方向。
- 歌词先预览，确认后再保存。
- 多个平行方向需要比较时，可使用 murpick 选择菜单。
- 默认使用成熟男声、中低音区、自然叙事和克制推进。
- 允许适当使用一两处 connected enjambment。
- 可以用喜剧形式表达悲剧，不直接说破、不直接讲道理。
- 歌名确认后，默认使用 `D:\MyPlaces\GPT Projects\自己\音乐创作\《歌名》\`。
- 路径不存在时暂停保存并通知用户。
- 自动根据产物判断进度，用户可以手动覆盖状态。
- Suno Style 必须实际统计字符数，不能超过1000字符。
- 发布物固定标出 `Aaron，Z作品`，并兼容手机、平板和桌面设备。

## 版本规范

每首歌的创作记录包含轻量的“创作背景与共鸣”，记录为什么写、想抓住什么、突出什么和表达什么。已确认版本不覆盖，旧版本进入 `archive/`。
